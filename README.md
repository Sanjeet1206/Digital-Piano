🎹 Digital Piano

A simple and interactive Digital Piano built using web technologies that allows users to play musical notes using their keyboard or mouse. This project is perfect for beginners to understand event handling and audio integration in web development.

🚀 Features
🎵 Play piano sounds using keyboard keys
🖱️ Click on piano keys to produce sound
🎶 Realistic audio effects
💻 Responsive and user-friendly interface
⚡ Lightweight and fast
🛠️ Technologies Used
HTML – Structure of the piano
CSS – Styling and layout
JavaScript – Functionality and sound handling

🎯 How It Works
Each key on the piano is mapped to a specific keyboard key.
When a user presses a key or clicks on the piano, a corresponding sound file is played using JavaScript.
